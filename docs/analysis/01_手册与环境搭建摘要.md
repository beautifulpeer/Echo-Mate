# Echo-Mate 手册与环境搭建摘要

## 1. 手册页面传达的核心信息

你给出的官网页面主要是“环境搭建”章节。它不是业务逻辑说明文档，而是**项目启动前的准备指南**，重点包括：

- 必要硬件：Windows 电脑、Echo RV1106 开发板、USB 线、SD 卡、读卡器，串口模块可选。
- 驱动工具：需要安装 Rockchip 相关驱动助手。
- 推荐开发环境：**Ubuntu 22.04**。
- 拉取方式：完整仓库 + 子模块 + Git LFS。
- 后续说明入口：页面里明确指向了后续的 SDK 说明、整体软件说明、DeskBot 例程说明等章节。

## 2. 推荐的软件环境

根据官网手册和仓库自带说明，推荐准备如下环境：

### 主机环境

- Ubuntu 22.04
- Git、repo、cmake、gcc/g++、buildroot 编译依赖
- 若需要运行 AIChat 的服务器端，还需要 Python 3.10 虚拟环境

### 获取源码

```bash
git clone https://github.com/No-Chicken/Echo-Mate.git
cd Echo-Mate
git submodule update --init --recursive
git lfs pull
git submodule foreach --recursive 'git lfs pull'
```

## 3. 仓库分层理解

从仓库结构看，这个项目可以拆成两部分：

### A. 上层应用与 demo

位于 Demo 目录，负责：
- 图形界面
- AI 对话
- 视觉识别
- 板级功能演示

### B. 底层 SDK 与系统镜像

位于 SDK 目录，负责：
- 内核与 rootfs
- 板卡配置
- 驱动与设备树
- 固件编译和烧录

## 4. 开发时最常见的三条路径

### 路径 1：只想先看效果

直接看 Demo 下的各个示例，特别是：
- DeskBot_demo
- AIChat_demo
- yolov5_demo

### 路径 2：要做板端系统开发

重点看：
- SDK/README.md
- SDK/rv1106-sdk 下的 build.sh、project、sysdrv

### 路径 3：要做 AI 语音能力扩展

重点看：
- AIChat_demo/Client
- AIChat_demo/Server

## 5. 编译与运行上的关键前提

### DeskBot_demo

- 可以在 Ubuntu 下用 SDL 仿真运行
- 也可以交叉编译到 RV1106 开发板
- 聊天功能依赖 AIChat 的服务端先启动

### AIChat_demo

- Client 在板端或 PC 侧运行
- Server 在电脑侧运行
- 二者通过 WebSocket 通信
- 语音数据是 Opus，控制消息用 JSON

### yolov5_demo

- 依赖 RV1106 平台、摄像头、RKNN 模型
- 重点是模型推理 + 屏幕显示链路

## 6. 结论

这套工程的特点不是“一个小程序”，而是：

1. **有完整硬件平台背景**
2. **有系统层 SDK**
3. **有应用层 LVGL 桌面 UI**
4. **有独立的语音 AI 和视觉 AI demo**

所以建议先把它理解为：

> 一套面向 RV1106 桌面机器人产品化方向的综合工程，而不是单一示例代码。
